# Bundled fonts

Only OFL (or similarly permissive) fonts live here. Typst is run with `--ignore-system-fonts`,
so books render the same on every machine: these files + Typst's embedded fonts
(Libertinus Serif, New Computer Modern, DejaVu Sans Mono) are all that is available.

| Family | Use | License |
|---|---|---|
| Atkinson Hyperlegible (Regular, Bold) | grids, headings, large print | OFL 1.1 (`OFL-atkinsonhyperlegible.txt`) |
| Courier Prime (Regular, Bold) | typewriter / case files | OFL 1.1 (`OFL-courierprime.txt`) |
| Libertinus Serif (embedded in Typst) | prose | OFL 1.1 |

Source: github.com/google/fonts (ofl/).
