# Puzzle Forge

Puzzle Forge produces print-ready, English-language puzzle books for Amazon KDP: classic puzzle books
(word search, crossword, sudoku, maze, cryptogram, word scramble, logic grid…) and "solve the case"
mystery puzzle books where each solved puzzle yields evidence that unlocks the next part of the story.
Every puzzle is generated by deterministic code and re-verified by an independent solver; AI only writes
words, clues and prose.
