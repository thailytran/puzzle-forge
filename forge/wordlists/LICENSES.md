# Word list sources

- `data/enable1.txt.gz` — ENABLE2K word list (Enhanced North American Benchmark Lexicon),
  public domain. Copied from github.com/dolph/dictionary (`enable1.txt`). Used only as a
  dictionary for uniqueness checks (scramble anagrams, cryptogram decodings).
- `data/*.txt` theme lists, `quotes.txt` — written for this project (proverbs and quotations
  by authors who died more than 100 years ago, i.e. public domain).
- `data/scowl35.txt.gz` — SCOWL (Spell Checker Oriented Word Lists) sizes 10+20+35, lowercase
  a-z words only: common English, used by the cryptogram solver. © Kevin Atkinson, permissive
  license (see `SCOWL-COPYRIGHT.txt`, which must ship with the list).
